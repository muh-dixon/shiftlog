# ShiftLog

## Problem Statement

Small service teams often rely on informal messages, paper notes, or scattered documents to pass operational context between shifts. ShiftLog will provide a focused workspace for handovers, task visibility, and manager oversight.

## Target Users

- Frontline service staff handing off daily work
- Shift leads coordinating open tasks and incidents
- Managers reviewing team operations and follow-up needs

## Planned Stack

- Next.js App Router
- TypeScript
- TailwindCSS
- Supabase
- React Hook Form
- Zod
- Recharts
- Jest
- React Testing Library
- GitHub Actions
- Vercel

## MVP Goals

- Capture shift handover notes
- Track open operational tasks
- Provide a dashboard for recent shift activity
- Support manager review workflows
- Establish automated lint, test, and build checks
